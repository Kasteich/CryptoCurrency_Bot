# CryptoCurrency_Bot

Этот проект — Telegram-бот для отслеживания курсов валют и криптовалют. Бот позволяет получать актуальные данные по фиатным валютам и криптовалютам, а также конвертировать одну валюту в другую.

## Описание

Бот использует следующие API:
- **Open Exchange Rates** для получения данных о фиатных валютах. [Получить API-ключ](https://openexchangerates.org/signup).
- **CoinGecko** для получения данных о криптовалютах. [Документация API](https://www.coingecko.com/en/api).

Бот предоставляет следующие возможности:
- Получение текущего курса валют и криптовалют.
- Конвертация одной валюты в другую.
- Просмотр минимального и максимального курса за определённый период.
- История запросов пользователя.
- Получение списка популярных криптовалют.
- Удобная клавиатура с основными командами.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://gitlab.skillbox.ru/konstantin_ilin_2/CryptoCurrency_Bot.git
cd CryptoCurrency_Bot
```
### 2. Установка зависимостей
Убедитесь, что у вас установлен Python 3.8 или выше. Затем установите необходимые зависимости:

```bash
pip install -r requirements.txt
```

### 3. Настройка переменных окружения
Создайте файл .env в корне проекта и добавьте в него следующие переменные:
```plaintext
TOKEN=ваш_токен_бота
FIAT_API_KEY=ваш_api_ключ_для_Open_Exchange_Rates
CRYPTO_API_KEY=ваш_api_ключ_для_CoinGecko (если требуется)
DB_NAME=имя_вашей_базы_данных
```
### 4. Запуск бота
Запустите бота с помощью команды:
```bash
python main.py
```
Теперь вы можете начать использовать бота в Telegram.

## Доступные команды
- /start — начать работу с ботом.

- /help — получить список доступных команд.

- /price <символ валюты> — получить текущий курс криптовалюты или фиатной валюты (например, /price BTC или /price USD).

- /history — посмотреть историю запросов.

- /low <символ валюты> — минимальный курс за неделю/месяц.

- /high <символ валюты> — максимальный курс за неделю/месяц.

- /convert <сумма> <из валюты> <в валюту> — конвертировать сумму из одной валюты в другую (например, /convert 100 USD RUB).

- /currencies — получить список доступных валют и их символов.

- /crypto_currencies — получить список популярных криптовалют.

## Примеры использования
- Получить текущий курс биткоина:
```/price BTC```

- Конвертировать 100 долларов США в рубли:
```/convert 100 USD RUB```

- Получить минимальный курс евро за последнюю неделю:
```/low EUR```

- Получить список доступных валют:
```/currencies```

- Получить список популярных криптовалют:
```/crypto_currencies```

## База данных
Бот использует SQLite для хранения данных пользователей и истории запросов. 
База данных автоматически создаётся при первом запуске бота.

### Модели данных
- User: Хранит информацию о пользователях (user_id, username).

- QueryHistory: Хранит историю запросов пользователей (user, query_type, currency, rate, timestamp).

### Клавиатуры
Бот поддерживает два типа клавиатур:

- ReplyKeyboardMarkup: Основная клавиатура с командами.

- InlineKeyboardMarkup: Клавиатура для выбора валюты.

### Примечания
- Для работы с API необходимо получить ключи доступа для Open Exchange Rates и CoinGecko.

- Используйте ISO 4217 для ввода валют (например, USD, EUR, BTC, ETH).

- Для тестирования API можно использовать предоставленные бесплатные ключи или создать свои собственные.
